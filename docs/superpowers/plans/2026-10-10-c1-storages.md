# C1 Storages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Register storages (a local folder or an S3-compatible bucket) per server, let compose files use them through `${WF_STORAGE_<NAME>_<FIELD>}` variables, and manage them from a new Settings → Storages tab.

**Architecture:** The agent owns the registrations in `{AGENT_DATA_DIR}/storages/<name>.json` (atomic 0600 files, S3 secret ECIES ciphertext at rest) through a new `internal/infra/backup/storages` registry, reads and writes objects through new drivers in `internal/infra/backup/store` (`local`, `s3` via minio-go), and serves `storage.list|test|save|delete` from the Docker Compose orchestrator, which also resolves the referenced `WF_STORAGE_*` values into a never-committed `.winterflow/storage.env` on every deploy and now always passes the compose files with explicit `-f`. The API mirrors name/type/location (never a secret) into a new `server_storages` index kept current by the command results and by the agent-online sync (generalized from the domain sync), serves five storage routes, and refuses at save-app a compose file that references a missing storage or a user variable with a reserved prefix. The web gains a Storages tab with an add/edit dialog (secret encrypted in the browser) and read-only storage rows in the app editor's Variables panel.

**Tech Stack:** Go 1.25 (chi, bun over SQLite/Postgres, go-git, `github.com/minio/minio-go/v7` v7.3.0 (Apache-2.0); tests: `github.com/johannesboyne/gofakes3` v1.2.0 (MIT)), React 19 + Vite + Vitest + Testing Library, vendored shadcn/ui (Radix), pnpm.

**Spec:** `docs/superpowers/specs/2026-10-10-storages-and-backups-design.md` — only its "C1 — Storages" part. C2 (backups, `x-winterflow` recipes, the scheduler, the helper) is out of scope; where the spec says "(C2: …)" this plan leaves a seam (noted in comments) and implements nothing.

**Base:** branch `feat/storages` (HEAD `5a2b17a` = main + the spec). Every snippet below was built and its tests run on a copy of that commit, task by task. `New:` files are given whole; edits to existing files are given as exact *find → replace* blocks (whitespace matters: copy them as shown, then `gofmt -w` the file).

## Global Constraints

- Storage name: `^[a-z0-9]([a-z0-9-]{0,30}[a-z0-9])?$` (`model.ValidateStorageName`, mirrored by `storageNameError` in `web/src/lib/storages.ts`). Underscores are refused so two names never map to one variable.
- Storage types are exactly `local` | `s3`; exactly the sub-struct matching the type is set.
- Local path: absolute, cleaned, not `/`, not under `AGENT_DATA_DIR` (agent check); the folder must already exist — winterflow never creates it.
- S3 endpoint: `https://host[:port]`; `http://` only for loopback/private addresses (and `localhost`); no path/query/userinfo. Prefix: optional, no leading `/`, normalized to end with `/`.
- Fail closed on ownership: every storage route checks `webutil.RequireServerAccess` (through `serverFromQuery`); the contract matrix gets a `valid` and a `malformed` probe for each of the five routes (TestForeignServer asserts the 403).
- Secrets never leave the agent in plaintext: the browser ECIES-encrypts the S3 secret with the server key (`GET /api/v1/server/get-public-key`), the agent stores ciphertext and decrypts only in memory or into the 0600 `storage.env`; reads answer `<encrypted>`; secrets are never logged and never in the API database (`server_storages` holds name, type, location only).
- `<encrypted>` as the secret on test/save reuses the secret stored under the same name. Renaming is not supported.
- Every network operation has a deadline: `storage.test` (and the test `storage.save` runs first) 30 s; the `docker ps` of a save 30 s; each redeploy after a save 10 min.
- No new polling: storage listings, user scans and probes happen on request only; status collection is untouched.
- `storage.env` holds only the referenced variables, is passed between `.env` and `.env.secrets`, is gitignored, and can never be committed (go-git `Worktree.Excludes`).
- Command types are `storage.list`, `storage.test`, `storage.save`, `storage.delete`; every request with input has a `Validate()` the dispatcher runs; one registration line per type.
- No new env var (C1 adds none; the project rule — document any env var in `.env.example` in the same change — is not triggered).
- Coverage gate: ≥80% of changed lines per language (`make diffcov DIFFCOV_BASE=main`); `api/openapi.yaml` regenerated (`make openapi`) whenever routes or response types change.
- Never touch `web/src/components/ui/` (vendored shadcn). After `pnpm --dir web run build`, restore `web/dist/.gitkeep` (`touch web/dist/.gitkeep`) and never commit its deletion.
- UI copy: the add button reads **Add storage** (the user prefers "Add …" wording, like "Add domain").
- After editing `scripts/install.sh`, run `bash scripts/install_test.sh`.
- Commits: Conventional Commits (`feat(agent): …`, `feat(api): …`, `feat(web): …`, `test(contract): …`), each message ending with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A USB disk that is unplugged while its mount point (`/mnt/usb`) still exists: writes would land on the system disk. The docs tell users to register a subfolder created on the disk (`/mnt/usb/winterflow`), which disappears with the disk, and the local driver refuses a missing folder instead of creating it — Task 2 `TestOpenLocalNeedsAnExistingFolder`, Task 4 `TestSaveStorageRefusesWhatFailsItsTest`.
2. Rolling an app back to a revision whose `.gitignore` predates `storage.env` must never commit the plaintext secrets — Task 3 `TestMaterializeStorageEnv` (commits with a `.gitignore` that doesn't list it and asserts the file is not in HEAD).
3. Editing an S3 storage without retyping the secret keeps the stored one, for both Test connection and Save, and a typed secret never outlives the dialog — Task 4 `TestSaveStorageS3KeepsTheStoredSecret`, Task 8 `useDocker storage calls`, Task 9 "wipes a typed secret when the dialog closes".
4. Saving a storage must not start an app the user stopped, nor deploy an undeployed draft behind the user's back; a failing redeploy is a warning, not a failed save — Task 4 `TestSaveStorageRedeploysRunningUsers`.
5. Compose syntax around references: `$$` escapes, `${VAR:-default}`, unbraced `$VAR`, override files, a `compose.yaml` shadowing a `compose.yml` — Task 1 `TestScanStorageRefs`, `TestDetectComposeFiles`, Task 7 `TestSaveAppChecksStorageReferences`.

```go
func TestParseStorageRef(t *testing.T) {
	cases := map[string]StorageRef{
		"WF_STORAGE_HETZNER_BUCKET":            {Storage: "hetzner", Field: FieldBucket},
		"WF_STORAGE_BACKUP_DISK_PATH":          {Storage: "backup-disk", Field: FieldPath},
		"WF_STORAGE_A_SECRET_ACCESS_KEY":       {Storage: "a", Field: FieldSecretAccessKey},
		"WF_STORAGE_A_SECRET_ACCESS_KEY_ID":    {Storage: "a-secret", Field: FieldAccessKeyID},
		"WF_STORAGE_X1_TYPE":                   {Storage: "x1", Field: FieldType},
		"WF_STORAGE_MY_PREFIX_PREFIX":          {Storage: "my-prefix", Field: FieldPrefix},
		"WF_STORAGE_EU_ENDPOINT":               {Storage: "eu", Field: FieldEndpoint},
		"WF_STORAGE_EU_REGION":                 {Storage: "eu", Field: FieldRegion},
		"WF_STORAGE_HETZNER_ACCESS_KEY_ID":     {Storage: "hetzner", Field: FieldAccessKeyID},
		"WF_STORAGE_HETZNER_SECRET_ACCESS_KEY": {Storage: "hetzner", Field: FieldSecretAccessKey},
	}
	for v, want := range cases {
		want.Var = v
		got, err := ParseStorageRef(v)
		if err != nil || got != want {
			t.Errorf("%s: %+v, %v; want %+v", v, got, err, want)
		}
	}
	if !(StorageRef{Field: FieldSecretAccessKey}).Secret() || (StorageRef{Field: FieldBucket}).Secret() {
		t.Fatal("only the secret access key is a secret")
	}
	for v, want := range map[string]string{
		"WF_STORAGE_HETZNER_COLOR": "is not a storage variable",
		"WF_STORAGE_TYPE":          "is not a storage variable",
		"WF_STORAGE__X_TYPE":       "is not a storage variable",
		"WF_BACKUP_DB_PATH":        `there is no backup "db" in this app`,
		"WF_BACKUP_MEDIA_FILES":    `there is no backup "media-files" in this app`,
		"PATH":                     "is not a storage variable",
	} {
		_, err := ParseStorageRef(v)
		if err == nil || !errors.Is(err, ErrStorageRef) || !strings.Contains(err.Error(), want) {
			t.Errorf("%s: err = %v, want %q", v, err, want)
		}
	}
}
```

```go
// agent's {AGENT_DATA_DIR}/storages/ is the source of truth; the API mirrors
// name, type and location (never a secret) into its server_storages index.

// ErrStorageRef marks a save whose compose file references a WF_STORAGE_ /
// WF_BACKUP_ variable that resolves to nothing on the target server; the HTTP
// layer maps it to 400.
var ErrStorageRef = errors.New("unresolved storage variable")

// ErrReservedVariable marks a user variable whose name a storage provides;
// the HTTP layer maps it to 400.
var ErrReservedVariable = errors.New("reserved variable name")

// StorageType is the kind of a storage.
type StorageType string

const (
	StorageLocal StorageType = "local" // a folder on the server
	StorageS3    StorageType = "s3"    // an S3-compatible bucket
)

// Storage is one registration. Exactly the sub-struct matching Type is set.
type Storage struct {
	Name  string        `json:"name"`
	Type  StorageType   `json:"type"`
	Local *LocalStorage `json:"local,omitempty"`
	S3    *S3Storage    `json:"s3,omitempty"`
}

// LocalStorage is a folder on the server: absolute, cleaned, not "/", and
// (checked on the agent) not under AGENT_DATA_DIR. The folder must exist —
// winterflow never creates it, so an unmounted disk fails instead of filling
// the root filesystem.
type LocalStorage struct {
	Path string `json:"path"`
}

// S3Storage is an S3-compatible bucket. SecretAccessKey is ECIES ciphertext
// in transit and at rest, or EncryptedPlaceholder ("keep the stored one");
// reads always answer the placeholder.
type S3Storage struct {
	Endpoint        string `json:"endpoint"`
	Region          string `json:"region"`
	Bucket          string `json:"bucket"`
	Prefix          string `json:"prefix"`
	AccessKeyID     string `json:"access_key_id"`
	SecretAccessKey string `json:"secret_access_key"`
	PathStyle       bool   `json:"path_style"`
}

// StorageSummary is what the API's index keeps of a storage: never a secret.

	Name     string      `json:"name"`
	Type     StorageType `json:"type"`
	Location string      `json:"location"`
}

// app secrets use: command.EncryptedPlaceholder).

var (
	storageNameRE = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,30}[a-z0-9])?$`)
	bucketRE      = regexp.MustCompile(`^[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]$`)
	regionRE      = regexp.MustCompile(`^[a-z0-9_-]{0,64}$`)
)

// ValidateStorageName checks a storage name: lowercase letters, digits and
// inner hyphens, at most 32 characters. Underscores are refused so two names
// never map to the same WF_STORAGE_ variable.
func ValidateStorageName(name string) error {
	if !storageNameRE.MatchString(name) {
		return fmt.Errorf("%q is not a valid storage name: use 1-32 lowercase letters, digits and inner hyphens, like backup-disk", name)
	}
	return nil
}

// Normalized returns s with the forms the agent stores: a cleaned local
// path, an endpoint without a trailing slash, and a prefix ending in "/"
// (or empty). It never fails; Validate judges the result.
func (s Storage) Normalized() Storage {
	out := s
	if s.Local != nil {
		l := *s.Local
		if p := strings.TrimSpace(l.Path); p != "" {
			l.Path = filepath.Clean(p)
		}
		out.Local = &l
	}
	if s.S3 != nil {
		c := *s.S3
		c.Endpoint = strings.TrimRight(strings.TrimSpace(c.Endpoint), "/")
		c.Region = strings.TrimSpace(c.Region)
		c.Bucket = strings.TrimSpace(c.Bucket)
		c.AccessKeyID = strings.TrimSpace(c.AccessKeyID)
		c.Prefix = strings.TrimSpace(c.Prefix)
		if c.Prefix != "" && !strings.HasSuffix(c.Prefix, "/") {
			c.Prefix += "/"
		}
		out.S3 = &c
	}
	return out
}

// Validate checks a storage as Normalized would store it.
func (s Storage) Validate() error {
	s = s.Normalized()
	if err := ValidateStorageName(s.Name); err != nil {
		return err
	}
	switch s.Type {
	case StorageLocal:
		if s.Local == nil || s.S3 != nil {
			return errors.New("a local storage needs local settings only")
		}
		return s.Local.validate()
	case StorageS3:
		if s.S3 == nil || s.Local != nil {
			return errors.New("an s3 storage needs s3 settings only")
		}
		return s.S3.validate()
	default:
		return fmt.Errorf("storage type must be local or s3, got %q", s.Type)
	}
}

func (l LocalStorage) validate() error {
	if !filepath.IsAbs(l.Path) || strings.ContainsRune(l.Path, 0) {
		return fmt.Errorf("the folder must be an absolute path like /mnt/backup, got %q", l.Path)
	}
	if l.Path == "/" {
		return errors.New("the folder cannot be / itself")
	}
	return nil
}

func (c S3Storage) validate() error {
	if err := validateEndpoint(c.Endpoint); err != nil {
		return err
	}
	if !regionRE.MatchString(c.Region) {
		return fmt.Errorf("%q is not a valid region", c.Region)
	}
	if !bucketRE.MatchString(c.Bucket) || strings.Contains(c.Bucket, "..") {
		return fmt.Errorf("%q is not a valid bucket name", c.Bucket)
	}
	if err := validatePrefix(c.Prefix); err != nil {
		return err
	}
	if c.AccessKeyID == "" || len(c.AccessKeyID) > 128 || strings.ContainsAny(c.AccessKeyID, " \t\r\n") {
		return errors.New("the access key id is required and cannot contain spaces")
	}
	if c.SecretAccessKey == "" {
		return errors.New("the secret access key is required")
	}
	return nil
}

// validateEndpoint accepts https://host[:port], and http:// only for a
// loopback or private address (MinIO on the LAN): credentials must not cross
// the internet in clear text.
func validateEndpoint(endpoint string) error {
	u, err := url.Parse(endpoint)
	if err != nil || u.Host == "" || u.User != nil || u.Path != "" || u.RawQuery != "" || u.Fragment != "" {
		return fmt.Errorf("the endpoint must be a URL like https://s3.example.com, got %q", endpoint)
	}
	switch u.Scheme {
	case "https":
		return nil
	case "http":
		if privateHost(u.Hostname()) {
			return nil
		}
		return fmt.Errorf("use https for %s: plain http is only allowed for a loopback or private address", u.Host)
	default:
		return fmt.Errorf("the endpoint must start with https://, got %q", endpoint)
	}
}

func privateHost(host string) bool {
	if host == "localhost" {
		return true
	}
	ip := net.ParseIP(host)
	return ip != nil && (ip.IsLoopback() || ip.IsPrivate() || ip.IsLinkLocalUnicast())
}

// validatePrefix accepts "" or "a/b/" style prefixes: no leading slash, no
// empty, "." or ".." segments.
func validatePrefix(p string) error {
	if p == "" {
		return nil
	}
	bad := len(p) > 512 || strings.HasPrefix(p, "/") || strings.ContainsAny(p, "\\\x00\r\n\t")
	for _, seg := range strings.Split(strings.TrimSuffix(p, "/"), "/") {
		if seg == "" || seg == "." || seg == ".." {
			bad = true
		}
	}
	if bad {
		return fmt.Errorf("%q is not a valid prefix: use folder names separated by /, like winterflow/", p)
	}
	return nil
}

	}
	return ""
}

// Summary is the index row of s.

}

		l := *s.Local

	}

// --- WF_STORAGE_* variables ---------------------------------------------------

const (
	storageVarPrefix = "WF_STORAGE_"
	backupVarPrefix  = "WF_BACKUP_"
)

// Storage variable fields. A field that does not apply to the storage's type
// resolves to empty.
const (
	FieldType            = "TYPE"
	FieldPrefix          = "PREFIX"
	FieldPath            = "PATH"
	FieldEndpoint        = "ENDPOINT"
	FieldRegion          = "REGION"
	FieldBucket          = "BUCKET"
	FieldAccessKeyID     = "ACCESS_KEY_ID"
	FieldSecretAccessKey = "SECRET_ACCESS_KEY"
)

// storageFields is every field, longest first so suffix matching picks
// ACCESS_KEY_ID before any shorter field could match.
var storageFields = []string{FieldSecretAccessKey, FieldAccessKeyID, FieldEndpoint, FieldPrefix, FieldRegion, FieldBucket, FieldType, FieldPath}

// StorageVarName is the variable for field of the storage named name.
func StorageVarName(name, field string) string {
	return storageVarPrefix + varToken(name) + "_" + field
}

func varToken(name string) string { return strings.ToUpper(strings.ReplaceAll(name, "-", "_")) }

// StorageRef is one parsed WF_STORAGE_<STORAGE>_<FIELD> reference.
type StorageRef struct {
	Var     string // the variable name, e.g. WF_STORAGE_BACKUP_DISK_PATH
	Storage string // the storage name, e.g. backup-disk
	Field   string // e.g. PATH
}

// Secret reports whether the reference resolves to a secret.
func (r StorageRef) Secret() bool { return r.Field == FieldSecretAccessKey }

// storageRefRE finds references the way compose interpolates them: $NAME
// or ${NAME...}.
var storageRefRE = regexp.MustCompile(`\$\{?(WF_(?:STORAGE|BACKUP)_[A-Z0-9_]+)`)

// ScanStorageRefs returns the WF_STORAGE_ / WF_BACKUP_ variable names the
// contents reference, sorted and unique. "$$" is compose's escape for a
// literal "$", so a match preceded by an odd run of "$" is not a reference.
func ScanStorageRefs(contents ...[]byte) []string {
	seen := map[string]bool{}
	for _, c := range contents {
		for _, m := range storageRefRE.FindAllSubmatchIndex(c, -1) {
			dollars := 0
			for i := m[0] - 1; i >= 0 && c[i] == '$'; i-- {
				dollars++
			}
			if dollars%2 == 1 {
				continue
			}
			seen[string(c[m[2]:m[3]])] = true
		}
	}
	out := make([]string, 0, len(seen))
	for v := range seen {
		out = append(out, v)
	}
	sort.Strings(out)
	return out
}

// ParseStorageRef splits a referenced variable into storage and field. A
// WF_BACKUP_ reference names a backup of the app; there are none until
// backups exist (C2), so it is refused like any undeclared backup.
func ParseStorageRef(v string) (StorageRef, error) {
	rest, isStorage := strings.CutPrefix(v, storageVarPrefix)
	if !isStorage {
		if backup, ok := strings.CutPrefix(v, backupVarPrefix); ok {
			if token, _, ok := splitField(backup); ok {
				backup = token
			}
			return StorageRef{}, fmt.Errorf("%w: ${%s}: there is no backup %q in this app", ErrStorageRef, v, tokenName(backup))
		}
		return StorageRef{}, fmt.Errorf("%w: %s is not a storage variable", ErrStorageRef, v)
	}
	token, field, ok := splitField(rest)
	name := tokenName(token)
	if !ok || ValidateStorageName(name) != nil {
		return StorageRef{}, fmt.Errorf("%w: ${%s} is not a storage variable: use WF_STORAGE_<NAME>_<FIELD> with FIELD one of %s",
			ErrStorageRef, v, strings.Join([]string{FieldType, FieldPrefix, FieldPath, FieldEndpoint, FieldRegion, FieldBucket, FieldAccessKeyID, FieldSecretAccessKey}, ", "))
	}
	return StorageRef{Var: v, Storage: name, Field: field}, nil
}

// splitField cuts a known field suffix off "<TOKEN>_<FIELD>".
func splitField(s string) (token, field string, ok bool) {
	for _, f := range storageFields {
		if t, found := strings.CutSuffix(s, "_"+f); found && t != "" {
			return t, f, true
		}
	}
	return "", "", false
}

func tokenName(token string) string { return strings.ToLower(strings.ReplaceAll(token, "_", "-")) }

// CheckStorageRefs parses every reference and requires its storage to
// exist; the first problem is returned (wrapping ErrStorageRef).
func CheckStorageRefs(refs []string, exists func(name string) bool) ([]StorageRef, error) {
	out := make([]StorageRef, 0, len(refs))
	for _, v := range refs {
		ref, err := ParseStorageRef(v)
		if err != nil {
			return nil, err
		}
		if !exists(ref.Storage) {
			return nil, fmt.Errorf("%w: ${%s}: there is no storage %q on this server", ErrStorageRef, v, ref.Storage)
		}
		out = append(out, ref)
	}
	return out, nil
}

// StorageFieldValue is the value of field for s; secret is the decrypted
// secret access key (only read for that field).
func StorageFieldValue(s Storage, field, secret string) string {
	switch field {
	case FieldType:
		return string(s.Type)
	case FieldPath:
		if s.Local != nil {
			return s.Local.Path
		}
	case FieldPrefix:
		if s.S3 != nil {
			return s.S3.Prefix
		}
	case FieldEndpoint:
		if s.S3 != nil {
			return s.S3.Endpoint
		}
	case FieldRegion:
		if s.S3 != nil {
			return s.S3.Region
		}
	case FieldBucket:
		if s.S3 != nil {
			return s.S3.Bucket
		}
	case FieldAccessKeyID:
		if s.S3 != nil {
			return s.S3.AccessKeyID
		}
	case FieldSecretAccessKey:
		if s.S3 != nil {
			return secret
		}
	}

}

// ReservedVariableError refuses a user variable named like a storage
// variable: those values only ever come from the server's storages.

		return fmt.Errorf("%w: %s: variables starting with WF_STORAGE_ or WF_BACKUP_ are provided by the server's storages", ErrReservedVariable, name)
	}
	return nil
}
```

```go
// Package store is the object interface over a storage: a folder on the
// server (local) or an S3-compatible bucket (s3). Keys are relative,
// "/"-separated and never escape the storage's folder or prefix.
package store

import (
	"context"
	"fmt"
	"io"
	"path"
	"strings"
	"time"

	"winterflow/internal/domain/model"
)

// Object is one stored object; Key is relative to the storage's folder or
// prefix.
type Object struct {
	Key     string
	Size    int64
	ModTime time.Time
}

// Store reads and writes objects. Every call honors ctx's deadline.
type Store interface {
	// Put streams r into key, replacing it; a reader that fails leaves
	// no object behind.
	Put(ctx context.Context, key string, r io.Reader) error
	// Get opens key for reading; the caller closes it.
	Get(ctx context.Context, key string) (io.ReadCloser, error)
	// List returns the objects whose key starts with prefix ("" = all),
	// sorted by key.
	List(ctx context.Context, prefix string) ([]Object, error)
	// Delete removes keys; a missing key is not an error.
	Delete(ctx context.Context, keys ...string) error
}

// Open returns the Store for s. secret is the decrypted secret access key
// (s3 only; local ignores it).
func Open(s model.Storage, secret string) (Store, error) {
	s = s.Normalized()
	if err := s.Validate(); err != nil {
		return nil, err
	}
	switch s.Type {
	case model.StorageLocal:
		return openLocal(s.Local.Path)
	default:
		return openS3(*s.S3, secret)
	}
}

// cleanKey checks an object key: relative, "/"-separated, already clean,
// and not "." or "..". Leading-dot names (".winterflow-probe-…") are fine.
func cleanKey(key string) (string, error) {
	if key == "" || strings.HasPrefix(key, "/") || strings.ContainsAny(key, "\\\x00") ||
		path.Clean(key) != key || key == "." || key == ".." || strings.HasPrefix(key, "../") {
		return "", fmt.Errorf("invalid object key %q", key)
	}
	return key, nil
}

// cleanPrefix checks a List prefix: "" or a clean key, optionally ending
// in "/".
func cleanPrefix(prefix string) (string, error) {
	if prefix == "" {
		return "", nil
	}
	if _, err := cleanKey(strings.TrimSuffix(prefix, "/")); err != nil {
		return "", fmt.Errorf("invalid prefix %q", prefix)
	}
	return prefix, nil
}
```

```go
package store

import (
	"context"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"

// tmpSuffix marks a Put in progress; List never reports such files.
const tmpSuffix = ".tmp"

// local stores objects as files under root: directories 0700, files 0600,
// each Put written to <key>.tmp, fsynced and renamed into place.
type local struct{ root string }

// openLocal requires root to be an existing folder: winterflow never creates
// it, so an unmounted disk fails here instead of filling the root
// filesystem.
func openLocal(root string) (*local, error) {
	info, err := os.Stat(root)
	if err != nil {
		if errors.Is(err, fs.ErrNotExist) {
			return nil, fmt.Errorf("the folder %s does not exist (is the disk mounted?)", root)
		}
		return nil, fmt.Errorf("cannot open %s: %w", root, err)
	}
	if !info.IsDir() {
		return nil, fmt.Errorf("%s is not a folder", root)
	}
	return &local{root: root}, nil
}

func (l *local) file(key string) string { return filepath.Join(l.root, filepath.FromSlash(key)) }

func (l *local) Put(ctx context.Context, key string, r io.Reader) error {
	key, err := cleanKey(key)
	if err != nil {
		return err
	}
	dst := l.file(key)
	if err := os.MkdirAll(filepath.Dir(dst), 0o700); err != nil {
		return err
	}
	tmp := dst + tmpSuffix
	f, err := os.OpenFile(tmp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0o600)
	if err != nil {
		return err
	}
	_, err = io.Copy(f, ctxReader{ctx, r})
	if err == nil {
		err = f.Sync()
	}
	if cerr := f.Close(); err == nil {
		err = cerr
	}
	if err == nil {
		err = os.Rename(tmp, dst)
	}
	if err != nil {
		_ = os.Remove(tmp)
		return err
	}
	return nil
}

func (l *local) Get(_ context.Context, key string) (io.ReadCloser, error) {
	key, err := cleanKey(key)
	if err != nil {
		return nil, err
	}
	return os.Open(l.file(key))
}

func (l *local) List(ctx context.Context, prefix string) ([]Object, error) {
	prefix, err := cleanPrefix(prefix)
	if err != nil {
		return nil, err
	}
	// Walk only the folder the prefix lives in.
	start := l.root
	if i := strings.LastIndex(prefix, "/"); i >= 0 {
		start = l.file(prefix[:i])
	}
	var out []Object
	err = filepath.WalkDir(start, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			if errors.Is(err, fs.ErrNotExist) {
				return nil
			}
			return err
		}
		if err := ctx.Err(); err != nil {
			return err
		}
		if d.IsDir() || !d.Type().IsRegular() || strings.HasSuffix(p, tmpSuffix) {
			return nil
		}
		rel, err := filepath.Rel(l.root, p)
		if err != nil {
			return err
		}
		key := filepath.ToSlash(rel)
		if !strings.HasPrefix(key, prefix) {
			return nil
		}
		info, err := d.Info()
		if err != nil {
			return nil // removed meanwhile
		}
		out = append(out, Object{Key: key, Size: info.Size(), ModTime: info.ModTime()})
		return nil
	})
	if err != nil {
		return nil, err
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Key < out[j].Key })
	return out, nil
}

// Delete removes the files and then the folders left empty, up to root.
func (l *local) Delete(ctx context.Context, keys ...string) error {
	for _, key := range keys {
		if err := ctx.Err(); err != nil {
			return err
		}
		key, err := cleanKey(key)
		if err != nil {
			return err
		}
		if err := os.Remove(l.file(key)); err != nil && !errors.Is(err, fs.ErrNotExist) {
			return err
		}
		for dir := path.Dir(key); dir != "."; dir = path.Dir(dir) {
			if os.Remove(l.file(dir)) != nil {
				break
			}
		}
	}
	return nil
}

// ctxReader stops a copy once ctx is done.
type ctxReader struct {
	ctx context.Context
	r   io.Reader
}

func (c ctxReader) Read(p []byte) (int, error) {
	if err := c.ctx.Err(); err != nil {
		return 0, err
	}
	return c.r.Read(p)
}
```

```go
package store

import (
	"context"
	"io"
	"net/url"
	"sort"
	"strings"

	"github.com/minio/minio-go/v7"
	"github.com/minio/minio-go/v7/pkg/credentials"

	"winterflow/internal/domain/model"
)

// partSize is the multipart chunk of a streamed Put. minio-go buffers one
// part in memory; without an explicit size it would size parts for a 5 TiB
// object (hundreds of MiB). 16 MiB × 10,000 parts caps an object at ~160 GiB.
var partSize uint64 = 16 << 20

// s3 stores objects under prefix in bucket.
type s3 struct {
	client *minio.Client
	bucket string
	prefix string
}

func openS3(c model.S3Storage, secret string) (*s3, error) {
	u, err := url.Parse(c.Endpoint)
	if err != nil {
		return nil, err
	}
	lookup := minio.BucketLookupDNS
	if c.PathStyle {
		lookup = minio.BucketLookupPath
	}
	client, err := minio.New(u.Host, &minio.Options{
		Creds:        credentials.NewStaticV4(c.AccessKeyID, secret, ""),
		Secure:       u.Scheme == "https",
		Region:       c.Region,
		BucketLookup: lookup,
	})
	if err != nil {
		return nil, err
	}
	return &s3{client: client, bucket: c.Bucket, prefix: c.Prefix}, nil
}

func (s *s3) Put(ctx context.Context, key string, r io.Reader) error {
	key, err := cleanKey(key)
	if err != nil {
		return err
	}
	_, err = s.client.PutObject(ctx, s.bucket, s.prefix+key, r, -1, minio.PutObjectOptions{
		PartSize:    partSize,
		ContentType: "application/octet-stream",
		// No per-chunk payload signing: over https minio-go already sends
		// UNSIGNED-PAYLOAD (TLS protects the body), and hashing every chunk
		// costs CPU the target boxes don't have. Plain http is allowed only
		// for loopback/private endpoints.
		DisableContentSha256: true,
	})
	return err
}

func (s *s3) Get(ctx context.Context, key string) (io.ReadCloser, error) {
	key, err := cleanKey(key)
	if err != nil {
		return nil, err
	}
	obj, err := s.client.GetObject(ctx, s.bucket, s.prefix+key, minio.GetObjectOptions{})
	if err != nil {
		return nil, err
	}
	// GetObject is lazy: stat now so a missing key fails here, not on Read.
	if _, err := obj.Stat(); err != nil {
		_ = obj.Close()
		return nil, err
	}
	return obj, nil
}

func (s *s3) List(ctx context.Context, prefix string) ([]Object, error) {
	prefix, err := cleanPrefix(prefix)
	if err != nil {
		return nil, err
	}
	var out []Object
	for obj := range s.client.ListObjects(ctx, s.bucket, minio.ListObjectsOptions{Prefix: s.prefix + prefix, Recursive: true}) {
		if obj.Err != nil {
			return nil, obj.Err
		}
		key, ok := strings.CutPrefix(obj.Key, s.prefix)
		if !ok || key == "" {
			continue
		}
		out = append(out, Object{Key: key, Size: obj.Size, ModTime: obj.LastModified})
	}
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Key < out[j].Key })
	return out, nil
}

func (s *s3) Delete(ctx context.Context, keys ...string) error {
	for _, key := range keys {
		key, err := cleanKey(key)
		if err != nil {
			return err
		}
		err = s.client.RemoveObject(ctx, s.bucket, s.prefix+key, minio.RemoveObjectOptions{})
		if err != nil && minio.ToErrorResponse(err).Code != "NoSuchKey" {
			return err
		}
	}
	return nil
}
```

```go
// Package storages keeps the agent's storage registrations under
// {AGENT_DATA_DIR}/storages/: one <name>.json per storage, mode 0600 in a
// 0700 folder, each written atomically (temp file, fsync, rename, folder
// fsync). An S3 secret stays ECIES ciphertext at rest; it is decrypted only
// in memory, or into an app's 0600 gitignored storage.env at deploy. The
// folder is the source of truth the API's server_storages index mirrors.
package storages

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"log/slog"
	"os"
	"path/filepath"
	"sort"
	"strings"
	"sync"

	"winterflow/internal/domain/model"
)

// Registry reads and writes the storages/ folder. Methods are safe for
// concurrent use.
type Registry struct {
	dir string
	mu  sync.Mutex
}

func NewRegistry(dir string) *Registry { return &Registry{dir: dir} }

// Dir is the folder the registry owns.
func (r *Registry) Dir() string { return r.dir }

func (r *Registry) path(name string) string { return filepath.Join(r.dir, name+".json") }

// List returns every storage, sorted by name. A file that does not parse,
// fails validation, or names another storage than its file name is skipped
// and logged: one damaged file must not hide the others.
func (r *Registry) List() ([]model.Storage, error) {
	r.mu.Lock()
	defer r.mu.Unlock()
	entries, err := os.ReadDir(r.dir)
	if err != nil {
		if errors.Is(err, fs.ErrNotExist) {
			return nil, nil
		}
		return nil, fmt.Errorf("read storages: %w", err)
	}
	var out []model.Storage
	for _, e := range entries {
		name, ok := strings.CutSuffix(e.Name(), ".json")
		if !ok || e.IsDir() {
			continue
		}
		s, err := r.read(name)
		if err != nil {
			slog.Warn("skipping unreadable storage registration", "file", e.Name(), "error", err)
			continue
		}
		out = append(out, s)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, nil
}

// read loads and checks one registration; callers hold r.mu.
func (r *Registry) read(name string) (model.Storage, error) {
	raw, err := os.ReadFile(r.path(name))
	if err != nil {
		return model.Storage{}, err
	}
	var s model.Storage
	if err := json.Unmarshal(raw, &s); err != nil {
		return model.Storage{}, err
	}
	if s.Name != name {
		return model.Storage{}, fmt.Errorf("names %q", s.Name)
	}
	if err := s.Validate(); err != nil {
		return model.Storage{}, err
	}
	return s, nil
}

// Get returns the storage named name; ok is false when there is none.
func (r *Registry) Get(name string) (model.Storage, bool, error) {
	if err := model.ValidateStorageName(name); err != nil {
		return model.Storage{}, false, err
	}
	r.mu.Lock()
	defer r.mu.Unlock()
	s, err := r.read(name)
	if errors.Is(err, fs.ErrNotExist) {
		return model.Storage{}, false, nil
	}
	if err != nil {
		return model.Storage{}, false, fmt.Errorf("read storage %s: %w", name, err)
	}
	return s, true, nil
}

// Put writes (or replaces) a storage as given: callers resolve the
// "<encrypted>" placeholder first, so the stored secret is ciphertext.
func (r *Registry) Put(s model.Storage) error {
	s = s.Normalized()
	if err := s.Validate(); err != nil {
		return err
	}
	if s.S3 != nil && s.S3.SecretAccessKey == model.EncryptedSecret {
		return errors.New("refusing to store the <encrypted> placeholder as a secret")
	}
	raw, err := json.MarshalIndent(s, "", "  ")
	if err != nil {
		return err
	}
	r.mu.Lock()
	defer r.mu.Unlock()
	if err := os.MkdirAll(r.dir, 0o700); err != nil {
		return fmt.Errorf("create storages dir: %w", err)
	}
	return writeAtomic(r.path(s.Name), raw)
}

// Delete removes a storage and reports whether it existed.
func (r *Registry) Delete(name string) (bool, error) {
	if err := model.ValidateStorageName(name); err != nil {
		return false, err
	}
	r.mu.Lock()
	defer r.mu.Unlock()
	err := os.Remove(r.path(name))
	if errors.Is(err, fs.ErrNotExist) {
		return false, nil
	}
	if err != nil {
		return false, fmt.Errorf("delete storage %s: %w", name, err)
	}
	syncDir(r.dir)
	return true, nil
}

// writeAtomic writes data (mode 0600) to path via a fsynced temp file that
// is renamed into place; the folder is fsynced after. A failed step removes
// the temp file, leaving the old content in place.
func writeAtomic(path string, data []byte) error {
	tmp := path + ".tmp"
	f, err := os.OpenFile(tmp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0o600)
	if err == nil {
		_, err = f.Write(data)
		if err == nil {
			err = f.Sync()
		}
		if cerr := f.Close(); err == nil {
			err = cerr
		}
	}
	if err == nil {
		err = os.Rename(tmp, path)
	}
	if err != nil {
		_ = os.Remove(tmp)
		return fmt.Errorf("write %s: %w", filepath.Base(path), err)
	}
	syncDir(filepath.Dir(path))
	return nil
}

// syncDir fsyncs a folder so a rename or removal in it is durable. Best
// effort: some filesystems refuse to sync a folder.
func syncDir(dir string) {
	d, err := os.Open(dir)
	if err != nil {
		return
	}
	_ = d.Sync()
	_ = d.Close()
}
```

```go
// storageEnvRel holds the values of the WF_STORAGE_ variables an app's
// compose files reference, resolved at every deploy. Derived state with
// plaintext secrets: 0600, gitignored, and excluded from every commit
// whatever .gitignore says (neverCommitted).
const storageEnvRel = ".winterflow/storage.env"

// composeContents reads the app's compose files (missing ones skipped).
func (r *Repository) composeContents(dir string) ([][]byte, error) {
	var out [][]byte
	for _, f := range r.composeFiles(dir, r.appSourceSpec(dir)) {
		raw, err := os.ReadFile(filepath.Join(dir, f))
		if errors.Is(err, fs.ErrNotExist) {
			continue
		}
		if err != nil {
			return nil, err
		}
		out = append(out, raw)
	}
	return out, nil
}

// storageRefs lists the WF_STORAGE_ / WF_BACKUP_ variables the app's
// compose files reference.
func (r *Repository) storageRefs(dir string) ([]string, error) {
	contents, err := r.composeContents(dir)
	if err != nil {
		return nil, fmt.Errorf("read compose files: %w", err)
	}
	return model.ScanStorageRefs(contents...), nil
}

// materializeStorageEnv writes storage.env with exactly the variables the
// compose files reference — an app never receives credentials for a
// storage it doesn't mention — or removes it when they reference none. A
// reference to a storage this server doesn't have (deleted, or added to a
// git-sourced compose file upstream) fails the deploy.
func (r *Repository) materializeStorageEnv(dir string) error {
	refs, err := r.storageRefs(dir)
	if err != nil {
		return err
	}
	path := filepath.Join(dir, storageEnvRel)
	if len(refs) == 0 {
		if err := os.Remove(path); err != nil && !errors.Is(err, fs.ErrNotExist) {
			return err
		}
		return nil
	}
	list, err := r.storages.List()
	if err != nil {
		return err
	}
	byName := make(map[string]model.Storage, len(list))
	for _, s := range list {
		byName[s.Name] = s
	}
	parsed, err := model.CheckStorageRefs(refs, func(n string) bool { _, ok := byName[n]; return ok })
	if err != nil {
		return err
	}
	secrets := map[string]string{} // each storage's secret decrypted once
	vars := make([]resolvedItem, 0, len(parsed))
	for _, ref := range parsed {
		s := byName[ref.Storage]
		secret := ""
		if ref.Secret() && s.S3 != nil {
			if _, done := secrets[s.Name]; !done {
				plain, err := crypto.DecryptWithPrivateKey(r.cfg.GetAgentKeyPath(), s.S3.SecretAccessKey)
				if err != nil {
					return fmt.Errorf("decrypt the secret access key of storage %s: %w", s.Name, err)
				}
				secrets[s.Name] = plain
			}
			secret = secrets[s.Name]
		}
		vars = append(vars, resolvedItem{name: ref.Var, content: []byte(model.StorageFieldValue(s, ref.Field, secret))})
	}
	if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
		return err
	}
	if err := os.WriteFile(path, marshalEnv(vars), 0o600); err != nil {
		return err
	}
	// WriteFile's perm only applies on create.
	return os.Chmod(path, 0o600)
}

// storageVariables describes the referenced WF_STORAGE_ variables for the
// Variables panel: names and storages, never values.
func storageVariables(refs []string) []command.StorageVariable {
	var out []command.StorageVariable
	for _, v := range refs {
		ref, err := model.ParseStorageRef(v)
		if err != nil {
			continue
		}
		out = append(out, command.StorageVariable{Name: ref.Var, Storage: ref.Storage, Secret: ref.Secret()})
	}
	return out
}
```

```go
	cases := []struct {
		s    model.Storage

		want string
	}{

		{localStorage("d", "/srv/backups"), denied, "docs/recipes/backup-storage.md"},
		{localStorage("d", "/mnt/usb"), denied, "writable by the user winterflow runs as"},

		}
	}
}
```

```go
	}
	users, err := r.storageUsers()
	if err != nil {
		r.log.Warn("storage list: some apps could not be checked", "error", err)
	}
	out := make([]command.StorageInfo, 0, len(list))
	for _, s := range list {
		out = append(out, describeStorage(s, users[s.Name]))
	}
	return out, nil
}

func describeStorage(s model.Storage, apps []string) command.StorageInfo {
	return command.StorageInfo{Storage: s.Masked(), Location: s.Location(), Apps: apps}
}

// storageUsers maps each storage name to the ids of the apps (in id order)
// whose compose files reference it. File reads only, on request — never
// polled. An app whose compose files can't be read is reported in the error
// while the map keeps every app read; callers that must not miss a user
// refuse on the error.
func (r *Repository) storageUsers() (map[string][]string, error) {
	users := map[string][]string{}
	entries, err := os.ReadDir(r.cfg.GetAppsDataDir())
	if errors.Is(err, fs.ErrNotExist) {
		return users, nil
	}
	if err != nil {
		return users, err
	}
	var problems []string
	for _, e := range entries {
		if !e.IsDir() {
			continue
		}
		refs, err := r.storageRefs(filepath.Join(r.cfg.GetAppsDataDir(), e.Name()))
		if err != nil {
			problems = append(problems, e.Name()+": "+err.Error())
			continue
		}
		seen := map[string]bool{}
		for _, v := range refs {
			ref, err := model.ParseStorageRef(v)
			if err != nil || seen[ref.Storage] {
				continue
			}
			seen[ref.Storage] = true
			users[ref.Storage] = append(users[ref.Storage], e.Name())
		}
	}
	if len(problems) > 0 {
		return users, errors.New(strings.Join(problems, "; "))
	}
	return users, nil
}

// resolveStorage prepares a requested storage: normalized and validated, a
// local folder kept out of the agent's data dir, an S3 secret resolved
// ("<encrypted>" reuses the one stored under the same name) and decrypted.
// The returned storage still carries the ciphertext, ready to store; secret
// is the plaintext, which only ever lives in memory here.
func (r *Repository) resolveStorage(in model.Storage) (model.Storage, string, error) {
	s := in.Normalized()
	if err := s.Validate(); err != nil {
		return model.Storage{}, "", err
	}
	if s.Type == model.StorageLocal {
		data, err := filepath.Abs(r.cfg.GetAgentDataDir())
		if err == nil && within(s.Local.Path, data) {
			return model.Storage{}, "", fmt.Errorf("the folder cannot be inside winterflow's data folder %s", data)
		}
		return s, "", nil
	}
	if s.S3.SecretAccessKey == model.EncryptedSecret {
		prev, ok, err := r.storages.Get(s.Name)
		if err != nil {
			return model.Storage{}, "", err
		}
		if !ok || prev.S3 == nil {
			return model.Storage{}, "", fmt.Errorf("enter the secret access key: %s has none stored", s.Name)
		}
		s.S3.SecretAccessKey = prev.S3.SecretAccessKey
	}
	secret, err := crypto.DecryptWithPrivateKey(r.cfg.GetAgentKeyPath(), s.S3.SecretAccessKey)
	if err != nil {
		return model.Storage{}, "", fmt.Errorf("decrypt the secret access key: %w", err)
	}
	return s, secret, nil
}

// within reports whether path is dir or inside it.
func within(path, dir string) bool {
	rel, err := filepath.Rel(dir, path)
	return err == nil && rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))
}

// probeStorage writes and deletes a probe object within storageProbeTimeout.
func probeStorage(ctx context.Context, s model.Storage, secret string) error {
	ctx, cancel := context.WithTimeout(ctx, storageProbeTimeout)
	defer cancel()
	st, err := store.Open(s, secret)
	if err != nil {
		return err
	}
	var b [8]byte
	_, _ = rand.Read(b[:])
	key := ".winterflow-probe-" + hex.EncodeToString(b[:])
	if err := st.Put(ctx, key, strings.NewReader("winterflow storage probe\n")); err != nil {
		return explainWrite(s, err)
	}
	if err := st.Delete(ctx, key); err != nil {
		return fmt.Errorf("the test file was written but could not be deleted: %w", err)
	}
	return nil
}

// explainWrite turns a refused local write into advice: outside /mnt and
// /media the systemd unit (ProtectSystem=strict) keeps the folder read-only
// for the agent; inside them it is plain file permissions.
func explainWrite(s model.Storage, err error) error {
	if s.Type != model.StorageLocal || !(errors.Is(err, fs.ErrPermission) || errors.Is(err, syscall.EROFS)) {
		return fmt.Errorf("write a test file: %w", err)
	}
	for _, root := range mountRoots {
		if within(s.Local.Path, root) {
			return fmt.Errorf("cannot write to %s: %w — make the folder writable by the user winterflow runs as", s.Local.Path, err)
		}
	}
	return fmt.Errorf("cannot write to %s: %w — the winterflow service may only write under /mnt and /media; "+
		"to use this folder, allow it with a systemd drop-in (see docs/recipes/backup-storage.md)", s.Local.Path, err)
}

// TestStorage checks a storage without saving it. Any problem — bad input,
// an unknown secret, a failed probe — is reported in the response, not as a
// command error, so the UI can show it inline.
func (r *Repository) TestStorage(ctx context.Context, in model.Storage) (command.TestStorageResponse, error) {
	s, secret, err := r.resolveStorage(in)
	if err == nil {
		err = probeStorage(ctx, s, secret)
	}
	if err != nil {
		return command.TestStorageResponse{OK: false, Error: err.Error()}, nil
	}
	return command.TestStorageResponse{OK: true}, nil
}

// SaveStorage tests a storage, stores it, and redeploys the running apps
// that reference it so they read the new values. Nothing is stored when the
// test fails. Redeploy problems are warnings: the storage is saved.
func (r *Repository) SaveStorage(ctx context.Context, in model.Storage) (command.SaveStorageResponse, error) {
	s, secret, err := r.resolveStorage(in)
	if err != nil {
		return command.SaveStorageResponse{}, err
	}
	if err := probeStorage(ctx, s, secret); err != nil {
		return command.SaveStorageResponse{}, fmt.Errorf("the connection test failed, nothing was saved: %w", err)
	}
	if err := r.storages.Put(s); err != nil {
		return command.SaveStorageResponse{}, err
	}
	users, err := r.storageUsers()
	resp := command.SaveStorageResponse{Storage: describeStorage(s, users[s.Name])}
	if err != nil {
		resp.Warnings = append(resp.Warnings, "some apps could not be checked for this storage: "+err.Error())
	}
	redeployed, warnings := r.redeployStorageUsers(ctx, users[s.Name])
	resp.Redeployed = redeployed
	resp.Warnings = append(resp.Warnings, warnings...)
	return resp, nil
}

// redeployStorageUsers brings the running apps among ids up again so they
// read the new storage.env. A stopped app stays stopped (its next start
// resolves the values). An app with undeployed changes is skipped with a
// warning: bringing it up would deploy its draft.
func (r *Repository) redeployStorageUsers(ctx context.Context, ids []string) (redeployed, warnings []string) {
	if len(ids) == 0 {
		return nil, nil
	}
	psCtx, cancel := context.WithTimeout(ctx, storageDockerTimeout)
	running, err := r.runningProjects(psCtx)
	cancel()
	if err != nil {
		return nil, []string{"could not check which apps are running, so none was redeployed: " + err.Error()}
	}
	for _, id := range ids {
		if !running[projectName(id)] {
			continue
		}
		name := r.appName(r.appDataDir(id), id)
		if r.hasDraft(id) {
			warnings = append(warnings, name+" has undeployed changes and was not redeployed: deploy it to use the new storage settings")
			continue
		}
		upCtx, cancel := context.WithTimeout(ctx, storageRedeployTimeout)
		err := r.redeploy(upCtx, id)
		cancel()
		if err != nil {
			warnings = append(warnings, fmt.Sprintf("%s: redeploy failed: %v", name, err))
			continue
		}
		redeployed = append(redeployed, id)
	}
	return redeployed, warnings
}

// composeProjectsUp is the set of compose projects with containers (one
// `docker ps`): the apps that are up, or crashed rather than stopped.
func (r *Repository) composeProjectsUp(ctx context.Context) (map[string]bool, error) {
	byProject, err := r.dockerPSByProject(ctx)
	if err != nil {
		return nil, err
	}
	up := make(map[string]bool, len(byProject))
	for project, containers := range byProject {
		if len(containers) > 0 {
			up[project] = true
		}
	}
	return up, nil
}

// hasDraft reports whether the app's HEAD is ahead of what runs.
func (r *Repository) hasDraft(appID string) bool {
	dir := r.appDataDir(appID)
	deployed, ok := readDeployedMark(dir)
	if !ok {
		return false
	}
	head, err := gitHead(dir)
	return err == nil && head != deployed
}

// DeleteStorage removes a storage, refusing while an app references it (the
// error names the apps). It fails closed: when an app's compose files can't
// be read, it can't tell, so it refuses too.
func (r *Repository) DeleteStorage(_ context.Context, name string) error {
	users, err := r.storageUsers()
	if err != nil {
		return fmt.Errorf("cannot remove %s: the apps using it can't be checked: %w", name, err)
	}
	if ids := users[name]; len(ids) > 0 {
		names := make([]string, 0, len(ids))
		for _, id := range ids {
			names = append(names, r.appName(r.appDataDir(id), id))
		}
		return fmt.Errorf("%s is used by %s: remove its WF_STORAGE_ variables from those apps first", name, strings.Join(names, ", "))
	}
	existed, err := r.storages.Delete(name)
	if err != nil {
		return err
	}
	if !existed {
		return fmt.Errorf("there is no storage %s on this server", name)
	}
	return nil
}
```

````markdown
# Backup storage: a folder or an S3 bucket

A **storage** is a place on a server that backups and apps can write to: a
local folder (a USB disk, an NFS or CIFS share) or an S3-compatible bucket
(AWS S3, Cloudflare R2, Backblaze B2, Hetzner Object Storage, MinIO).
Storages are added per server under **Settings → Storages**.

Winterflow tests every storage before it saves it: it writes a small
`.winterflow-probe-…` file and deletes it again. A storage that fails the
test is not saved.

## An S3-compatible bucket

| Field | Example | Notes |
|---|---|---|
| Endpoint | `https://fsn1.your-objectstorage.com` | `https://` only; plain `http://` is accepted for a loopback or private address (MinIO on your LAN) |
| Region | `fsn1`, `auto` (R2), `us-east-1` | may be empty when the provider ignores it |
| Bucket | `my-backups` | must exist already |
| Prefix | `winterflow/` | optional; everything winterflow writes stays under it |
| Access key / secret | | the secret is encrypted in your browser; only the server can read it |
| Path-style | on for MinIO | leave off for providers that use `bucket.endpoint` hostnames |

To edit a storage without re-entering the secret, leave the secret empty.

## A local folder

The folder must already exist: winterflow never creates it, so a USB disk
that isn't mounted fails the test instead of filling up the system disk.
It also must not be inside winterflow's own data folder.

The installer's systemd unit runs winterflow with `ProtectSystem=strict`:
the service can write only its data folder, the Docker socket, and
everything under **`/mnt`** and **`/media`**. Mount your disks or shares
there:

sudo mount /dev/sdb1 /mnt/backup          # or an /etc/fstab entry
sudo mkdir -p /mnt/backup/winterflow
sudo chown winterflow:winterflow /mnt/backup/winterflow
```

```

## Using a storage in an app

An app's compose file can reference any storage on its server by name with
`${WF_STORAGE_<NAME>_<FIELD>}`, where `<NAME>` is the storage name in upper
case with `-` replaced by `_`:

| Field | Applies to |
|---|---|
| `TYPE`, `PREFIX` | every storage (`PREFIX` is empty for a local folder) |
| `PATH` | local folders |
| `ENDPOINT`, `REGION`, `BUCKET`, `ACCESS_KEY_ID`, `SECRET_ACCESS_KEY` | S3 buckets |

For example, Litestream replicating a SQLite database to a storage named
`hetzner`:

```yaml
services:
  litestream:
    image: litestream/litestream:0.3
    command: replicate /data/app.db s3://${WF_STORAGE_HETZNER_BUCKET}/${WF_STORAGE_HETZNER_PREFIX}app.db
    environment:
      LITESTREAM_ACCESS_KEY_ID: ${WF_STORAGE_HETZNER_ACCESS_KEY_ID}
      LITESTREAM_SECRET_ACCESS_KEY: ${WF_STORAGE_HETZNER_SECRET_ACCESS_KEY}
      LITESTREAM_ENDPOINT: ${WF_STORAGE_HETZNER_ENDPOINT}
    volumes:
      - data:/data
```

- Only the variables the compose file mentions are passed to the app, so an
  app never receives credentials for a storage it doesn't use.
- Saving an app that references a storage the server doesn't have fails
  with the variable's name.
- The variables show up read-only in the app's **Variables** panel. You
  can't define your own variables starting with `WF_STORAGE_` or
  `WF_BACKUP_`.
- Saving a storage redeploys the running apps that reference it, so they
  pick up the new values. A storage can't be removed while an app
  references it.
````

```go
func NewDbServerStorageRepository(db *db.BunConnection, log *logger.Logger) *DbServerStorageRepository {

// DbServerStorageRepository maintains the server_storages index. The agent's
// storages/ dir stays authoritative; every method here is cache maintenance.
type DbServerStorageRepository struct {
	db  *db.BunConnection
	log *logger.Logger
}

func serverStorageRow(serverID string, s model.StorageSummary) models.ServerStorage {
	return models.ServerStorage{
		ServerID: serverID, Name: s.Name, Type: string(s.Type), Location: s.Location,
		UpdatedAt: types.DateTime(time.Now().UTC()),
	}
}

// ListForServer returns the server's storages sorted by name.
func (r *DbServerStorageRepository) ListForServer(ctx context.Context, serverID string) ([]model.StorageSummary, error) {
	return listServerStorages(ctx, r.db.GetDB(), serverID)
}

func listServerStorages(ctx context.Context, db bun.IDB, serverID string) ([]model.StorageSummary, error) {
	var rows []models.ServerStorage
	if err := db.NewSelect().Model(&rows).
		Where("server_id = ?", serverID).Order("name ASC").Scan(ctx); err != nil {
		return nil, err
	}
	out := make([]model.StorageSummary, 0, len(rows))
	for _, row := range rows {
		out = append(out, model.StorageSummary{Name: row.Name, Type: model.StorageType(row.Type), Location: row.Location})
	}
	return out, nil
}

// Upsert records one storage (storage.save confirmed by the agent).
func (r *DbServerStorageRepository) Upsert(ctx context.Context, serverID string, s model.StorageSummary) error {
	row := serverStorageRow(serverID, s)
	_, err := r.db.GetDB().NewInsert().Model(&row).
		On("CONFLICT (server_id, name) DO UPDATE").
		Set("type = EXCLUDED.type").
		Set("location = EXCLUDED.location").
		Set("updated_at = EXCLUDED.updated_at").
		Exec(ctx)
	return err
}

// Delete drops one storage (storage.delete confirmed by the agent).
func (r *DbServerStorageRepository) Delete(ctx context.Context, serverID, name string) error {
	_, err := r.db.GetDB().NewDelete().Model((*models.ServerStorage)(nil)).
		Where("server_id = ?", serverID).Where("name = ?", name).Exec(ctx)
	return err
}

// ReplaceForServer makes the index mirror a storage.list answer. An answer
// equal to the stored rows (every agent reconnect sends one) writes nothing.
func (r *DbServerStorageRepository) ReplaceForServer(ctx context.Context, serverID string, ss []model.StorageSummary) error {
	return r.db.GetDB().RunInTx(ctx, nil, func(ctx context.Context, tx bun.Tx) error {
		current, err := listServerStorages(ctx, tx, serverID)
		if err != nil {
			return err
		}
		if sameStorages(current, ss) {
			return nil
		}
		if _, err := tx.NewDelete().Model((*models.ServerStorage)(nil)).Where("server_id = ?", serverID).Exec(ctx); err != nil {
			return err
		}
		if len(ss) == 0 {
			return nil
		}
		rows := make([]models.ServerStorage, 0, len(ss))
		for _, s := range ss {
			rows = append(rows, serverStorageRow(serverID, s))
		}
		_, err = tx.NewInsert().Model(&rows).Exec(ctx)
		return err
	})
}

// sameStorages reports whether two lists hold the same rows, in any order.
func sameStorages(a, b []model.StorageSummary) bool {
	if len(a) != len(b) {
		return false
	}
	byName := make(map[string]model.StorageSummary, len(a))
	for _, s := range a {
		byName[s.Name] = s
	}
	for _, s := range b {
		if o, ok := byName[s.Name]; !ok || o != s {
			return false
		}
	}
	return true
}
```

```go
package bootstrap

import (
	"context"
	"sync"
	"time"

	"winterflow/internal/domain/port"
	appuc "winterflow/internal/domain/usecase/app"
	"winterflow/internal/infra/transport/bus"
	"winterflow/pkg/logger"

const (
	// indexSyncRetryDelay is the pause before the one retry of a sync the
	// hub bounced because the agent's stream was not active yet.
	indexSyncRetryDelay = 3 * time.Second
	// indexSyncTimeout bounds one attempt: past it an attempt whose result
	// never arrived no longer blocks the next one.
	indexSyncTimeout = time.Minute
	// indexSyncMaxAttempts caps the attempts per online period (the first
	// dispatch, its retry, re-fires on heartbeats), so a server the hub keeps
	// reporting as not connected is not asked again on every heartbeat.
	indexSyncMaxAttempts = 3
	// indexSyncPublishTimeout bounds the publish of one list command.
	indexSyncPublishTimeout = 10 * time.Second
)

// indexSync fills one of a server's API indexes (server_domains,
// server_storages) when its agent comes online: a list command dispatched
// for no user (the result reaches no SSE stream) whose result replaces the
// index rows, unchanged rows costing no write.
//
// In the distributed topology the hub publishes the capabilities event from
// RegisterAgent, before the agent's stream is active, so the first attempt
// usually bounces with bus.ErrAgentNotConnected. A sync therefore stays pending
// until a result arrives: a not-connected result is retried once after a
// short delay, and the agent's next heartbeat (EventServerOnline, sent as
// soon as the stream is up) re-fires a pending sync, up to
// indexSyncMaxAttempts. Any other result clears it — an agent without the
// list command answers an error that a retry would not change.
// Standalone's in-process bridge answers the first attempt, so it syncs once.
type indexSync struct {
	what       string // what is synced, for logs: "registered domains"
	ctx        context.Context
	list       func(ctx context.Context, serverID string) error
	retryDelay time.Duration
	log        *logger.Logger

	mu      sync.Mutex
	pending map[string]*syncState
}

type syncState struct {
	attempts      int
	retried       bool
	inFlightUntil time.Time
}

func newIndexSync(ctx context.Context, what string, log *logger.Logger) *indexSync {
	return &indexSync{what: what, ctx: ctx, retryDelay: indexSyncRetryDelay, log: log, pending: map[string]*syncState{}}
}

// newDomainSync fills server_domains through the app usecase's
// ListServerDomains, observing each result via a dispatcher tap.
func newDomainSync(ctx context.Context, d port.CommandDispatcher, repo port.ServerDomainRepository, log *logger.Logger) *indexSync {
	s := newIndexSync(ctx, "registered domains", log)
	uc := appuc.NewUseCase(&appuc.Deps{CommandDispatcher: resultTap{d, s.result}, ServerDomainRepository: repo, Log: log})
	s.list = func(ctx context.Context, serverID string) error {
		_, err := uc.ListServerDomains(ctx, "", serverID)
		return err
	}
	return s
}

// newStorageSync fills server_storages through ListServerStorages.
func newStorageSync(ctx context.Context, d port.CommandDispatcher, repo port.ServerStorageRepository, log *logger.Logger) *indexSync {
	s := newIndexSync(ctx, "storages", log)
	uc := appuc.NewUseCase(&appuc.Deps{CommandDispatcher: resultTap{d, s.result}, ServerStorageRepository: repo, Log: log})
	s.list = func(ctx context.Context, serverID string) error {
		_, err := uc.ListServerStorages(ctx, "", serverID)
		return err
	}
	return s
}

// indexSyncs drives every index sync from the same server events.
type indexSyncs []serverSync

func (all indexSyncs) online(serverID string) {
	for _, s := range all {
		s.online(serverID)
	}
}

func (all indexSyncs) heartbeat(serverID string) {
	for _, s := range all {
		s.heartbeat(serverID)
	}
}

// online starts a fresh sync for a server that came online or (re)registered.
func (s *indexSync) online(serverID string) {
	s.mu.Lock()
	st, ok := s.pending[serverID]
	if !ok || time.Now().After(st.inFlightUntil) {
		st = &syncState{}
		s.pending[serverID] = st
	}
	fire := s.claimLocked(st)
	s.mu.Unlock()
	if fire {
		s.dispatch(serverID)
	}
}

// heartbeat re-fires a pending sync: the agent's stream is active now.
func (s *indexSync) heartbeat(serverID string) {
	s.mu.Lock()
	st, ok := s.pending[serverID]
	fire := ok && s.claimLocked(st)
	s.mu.Unlock()
	if fire {
		s.dispatch(serverID)
	}
}

// claimLocked reserves an attempt unless one is in flight or the budget is
// spent.
func (s *indexSync) claimLocked(st *syncState) bool {
	now := time.Now()
	if now.Before(st.inFlightUntil) || st.attempts >= indexSyncMaxAttempts {
		return false
	}
	st.attempts++
	st.inFlightUntil = now.Add(indexSyncTimeout)
	return true
}

func (s *indexSync) dispatch(serverID string) {
	ctx, cancel := context.WithTimeout(s.ctx, indexSyncPublishTimeout)
	defer cancel()
	if err := s.list(ctx, serverID); err != nil {
		s.log.Warn("sync "+s.what+": dispatch the list", "error", err, "server_id", serverID)
		s.mu.Lock()
		if st, ok := s.pending[serverID]; ok {
			st.inFlightUntil = time.Time{}
		}
		s.mu.Unlock()
	}
}

// result settles an attempt: anything but not-connected clears the pending
// sync; not-connected keeps it for the next heartbeat and schedules the one
// retry.
func (s *indexSync) result(serverID string, res port.CommandResult) {
	s.mu.Lock()
	defer s.mu.Unlock()
	st, ok := s.pending[serverID]
	if !ok {
		return
	}
	if res.Success || res.Error != bus.ErrAgentNotConnected {
		if !res.Success {
			s.log.Debug("sync "+s.what+": agent answered an error", "error", res.Error, "server_id", serverID)
		}
		delete(s.pending, serverID)
		return
	}
	st.inFlightUntil = time.Time{}
	if st.attempts >= indexSyncMaxAttempts {
		s.log.Warn("sync "+s.what+": agent not connected, giving up until it comes online again", "server_id", serverID)
		delete(s.pending, serverID)
		return
	}
	if !st.retried {
		st.retried = true
		time.AfterFunc(s.retryDelay, func() {
			if s.ctx.Err() == nil {
				s.heartbeat(serverID)
			}
		})
	}
}

// resultTap is a dispatcher that reports every command's result, after the
// command's own OnResult, to tap.
type resultTap struct {
	port.CommandDispatcher
	tap func(serverID string, res port.CommandResult)
}

func (d resultTap) Dispatch(ctx context.Context, in port.DispatchInput) (string, error) {
	own, serverID := in.OnResult, in.AgentID
	in.OnResult = func(res port.CommandResult) {
		if own != nil {
			own(res)
		}
		d.tap(serverID, res)
	}
	return d.CommandDispatcher.Dispatch(ctx, in)
}
```

```ts
// storageBody is the API body for a draft; secret is the encrypted secret
// (or ENCRYPTED to keep the stored one).
export function storageBody(d: StorageDraft, secret: string) {
  if (d.type === "local") {
    return { name: d.name.trim(), type: "local" as const, local: { path: d.path.trim() } };
  }
  return {
    name: d.name.trim(),
    type: "s3" as const,

      endpoint: d.endpoint.trim(),
      region: d.region.trim(),
      bucket: d.bucket.trim(),
      prefix: d.prefix.trim(),
      access_key_id: d.accessKeyId.trim(),
      secret_access_key: secret,
      path_style: d.pathStyle,
    },

const NAME_RE = /^[a-z0-9]([a-z0-9-]{0,30}[a-z0-9])?$/;
const BUCKET_RE = /^[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]$/;

// storageNameError mirrors model.ValidateStorageName; "" means valid.
export function storageNameError(name: string): string {
  return NAME_RE.test(name)
    ? ""
    : "Use 1-32 lowercase letters, digits and inner hyphens, like backup-disk.";
}

// privateHost mirrors model.privateHost for IP literals and localhost.
function privateHost(host: string): boolean {
  if (host === "localhost" || host === "[::1]") return true;
  const m = /^(\d+)\.(\d+)\.(\d+)\.(\d+)$/.exec(host);
  if (!m) return false;
  const [a, b] = [Number(m[1]), Number(m[2])];
  return a === 127 || a === 10 || (a === 172 && b >= 16 && b <= 31) || (a === 192 && b === 168) || (a === 169 && b === 254);
}

// endpointError mirrors model.validateEndpoint; "" means valid.
export function endpointError(endpoint: string): string {
  let u: URL;
  try {
    u = new URL(endpoint.trim().replace(/\/+$/, ""));
  } catch {
    return "Use a URL like https://s3.example.com.";
  }
  if (u.pathname !== "/" || u.search || u.hash || u.username) {
    return "Use a URL like https://s3.example.com, without a path.";
  }
  if (u.protocol === "https:") return "";
  if (u.protocol === "http:") {
    return privateHost(u.hostname) ? "" : "Use https: plain http is only allowed for a local or private address.";
  }
  return "Use a URL like https://s3.example.com.";
}

// draftError is the first problem with a draft ("" when it can be sent).
// editing allows an empty secret (keep the stored one).
export function draftError(d: StorageDraft, editing: boolean): string {
  const nameErr = storageNameError(d.name.trim());
  if (nameErr) return nameErr;
  if (d.type === "local") {
    const p = d.path.trim();
    if (!p.startsWith("/")) return "Use an absolute folder path, like /mnt/backup.";
    if (/^\/+$/.test(p)) return "The folder cannot be / itself.";
    return "";
  }
  const endErr = endpointError(d.endpoint);
  if (endErr) return endErr;
  if (!BUCKET_RE.test(d.bucket.trim()) || d.bucket.includes("..")) return "Enter a valid bucket name.";
  const prefix = d.prefix.trim();
  if (prefix.startsWith("/") || prefix.split("/").some((seg, i, all) => (seg === "" && i < all.length - 1) || seg === "." || seg === "..")) {
    return "Use folder names separated by /, like winterflow/.";
  }
  if (!d.accessKeyId.trim() || /\s/.test(d.accessKeyId.trim())) return "Enter the access key.";
  if (!editing && !d.secret) return "Enter the secret key.";
  return "";
}

// storageVar is the compose variable for a storage's field, e.g.
// storageVar("backup-disk", "PATH") = "WF_STORAGE_BACKUP_DISK_PATH".
export function storageVar(name: string, field: string): string {
  return `WF_STORAGE_${name.toUpperCase().replaceAll("-", "_")}_${field}`;
}
```

```ts
      }>("/api/v1/storage/save", { method: "POST", body: await storageRequest(draft) });
      return { storage: res.storage, redeployed: res.redeployed ?? [], warnings: res.warnings ?? [] };
    },
    [dispatch, storageRequest],
  );

  const deleteStorage = useCallback(
    async (name: string): Promise<void> => {
      await dispatch("/api/v1/storage/delete", { method: "POST", body: { name } });
    },
    [dispatch],
  );
```

```tsx
// are its identity, so an edit shows them instead of offering them. The
// parent remounts it (key) per opening. Save tests again on the agent and

export function StorageDialog({
  docker,
  open,
  edit,
  onOpenChange,
  onSaved,
}: {
  docker: Docker;
  open: boolean;
  edit: Storage | null;
  onOpenChange: (open: boolean) => void;
  onSaved: (saved: StorageSaved) => void;
}) {

  const [probe, setProbe] = useState<Probe>({ state: "idle" });
  const [busy, setBusy] = useState(false);

  const error = draftError(draft, editing);
  const users = edit?.apps?.length ?? 0;

    setDraft((d) => ({ ...d, ...patch }));
    setProbe({ state: "idle" });

      setProbe({ state: "failed", error: e instanceof Error ? e.message : "The test failed." });
    }
  };

    setBusy(true);

      const saved = await docker.saveStorage(draft);
      changeOpen(false);
      onSaved(saved);

      toast.error(editing ? "Couldn't save storage" : "Couldn't add storage", {

                  : "Lowercase letters, digits and hyphens.",
              })}
            </>
```

```tsx
// UsedBy lists the apps whose compose files reference a storage, as chips
// linking to each app.
function UsedBy({ ids, names }: { ids: string[]; names: Map<string, string> }) {
  if (ids.length === 0) return <span className="text-muted-foreground">Not used</span>;
  return (
    <span className="flex flex-wrap gap-1">
      {ids.map((id) => (
        <Badge key={id} variant="secondary" className="font-medium">
          <Link to={`/app/${id}`} className="underline-offset-4 hover:underline">
            {names.get(id) ?? id}
          </Link>
        </Badge>
      ))}
    </span>
  );
}

const byName = (a: Storage, b: Storage) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0);

export function StoragesCard({ docker }: { docker: Docker }) {
  const { apps } = useApps();
  const [items, setItems] = useState<Storage[] | null>(null);
  const [loading, setLoading] = useState(true);
  const [dialogOpen, setDialogOpen] = useState(false);
  const [edit, setEdit] = useState<Storage | null>(null);
  const [dialogKey, setDialogKey] = useState(0);
  const [toDelete, setToDelete] = useState<Storage | null>(null);

  const load = useCallback(async () => {
    setLoading(true);
    try {
      setItems(await docker.listStorages());
    } catch (e) {
      toast.error("Failed to load storages", {
        description: e instanceof Error ? e.message : undefined,
      });
    } finally {
      setLoading(false);
    }
  }, [docker]);

  useEffect(() => {
    void load();
  }, [load]);

  const names = useMemo(() => new Map(apps.map((a) => [a.id, a.name])), [apps]);

  // A save answers with the stored storage: patch the list in place.
  const saved = ({ storage, redeployed, warnings }: StorageSaved) => {
    const done = edit ? "Storage saved" : "Storage added";
    const description =
      redeployed.length > 0
        ? `Redeployed ${redeployed.map((id) => names.get(id) ?? id).join(", ")}.`
        : undefined;
    if (warnings.length > 0) {
      toast.warning(`${done}, but not every app was redeployed`, {
        description: [description, ...warnings].filter(Boolean).join("\n"),
      });
    } else {
      toast.success(done, { description });
    }
    setItems((prev) => [...(prev ?? []).filter((s) => s.name !== storage.name), storage].sort(byName));
  };

  const remove = async (name: string) => {
    try {
      await docker.deleteStorage(name);
      toast.success("Storage removed");
      setItems((prev) => prev && prev.filter((s) => s.name !== name));
    } catch (e) {
      toast.error("Couldn't remove storage", {
        description: e instanceof Error ? e.message : undefined,
      });
    }
  };

  const openDialog = (row: Storage | null) => {
    setEdit(row);
    setDialogKey((k) => k + 1);
    setDialogOpen(true);
  };

  return (
    <Card>
      <CardHeader className="flex-row flex-wrap items-start justify-between gap-x-4 gap-y-3 space-y-0">
        <div className="min-w-0 space-y-1.5">
          <CardTitle>Storages</CardTitle>
          <CardDescription>
            Folders and S3-compatible buckets that backups and apps on this server can
            write to. Compose files use them as{" "}
            <code className="font-mono">{"${WF_STORAGE_<NAME>_<FIELD>}"}</code>.
          </CardDescription>
        </div>
        <div className="flex items-center gap-2">
          <Button
            size="icon"
            variant="ghost"
            className="size-8 text-muted-foreground"
            aria-label="Refresh storages"
            title="Refresh storages"
            onClick={() => void load()}
            disabled={loading}
          >
            <RefreshCw className={cn("size-4", loading && "animate-spin")} />
          </Button>
          <Button size="sm" onClick={() => openDialog(null)}>
            <Plus className="size-4" /> Add storage
          </Button>
        </div>
      </CardHeader>
      <CardContent>
        {items === null ? (
          <div className="flex h-24 items-center justify-center">
            {loading ? <Spinner /> : <p className="text-sm text-muted-foreground">Couldn't load storages.</p>}
          </div>
        ) : items.length === 0 ? (
          <p className="rounded-lg border border-dashed px-4 py-10 text-center text-sm text-muted-foreground">
            No storages yet. Add a folder, such as a USB disk under <code className="font-mono">/mnt</code>, or
            an S3 bucket.
          </p>
        ) : (
          <Table>
            <TableHeader>
              <TableRow>
                <TableHead>Name</TableHead>
                <TableHead>Type</TableHead>
                <TableHead className="hidden md:table-cell">Location</TableHead>
                <TableHead className="hidden sm:table-cell">Used by</TableHead>
                <TableHead className="w-20">
                  <span className="sr-only">Actions</span>
                </TableHead>
              </TableRow>
            </TableHeader>
            <TableBody>
              {items.map((s) => {
                const used = s.apps ?? [];
                return (
                  <TableRow key={s.name}>
                    <TableCell className="font-mono">{s.name}</TableCell>
                    <TableCell>
                      <Badge variant="outline" className="whitespace-nowrap">
                        {STORAGE_TYPES[s.type]}
                      </Badge>
                    </TableCell>
                    <TableCell className="hidden font-mono text-xs [overflow-wrap:anywhere] md:table-cell">
                      {s.location}
                    </TableCell>
                    <TableCell className="hidden sm:table-cell">
                      <UsedBy ids={used} names={names} />
                    </TableCell>
                    <TableCell className="whitespace-nowrap py-0.5 text-right">
                      <Button
                        size="icon"
                        variant="ghost"
                        className="size-8 text-muted-foreground"
                        aria-label={`Edit storage ${s.name}`}
                        title="Edit storage"
                        onClick={() => openDialog(s)}
                      >
                        <Pencil className="size-4" />
                      </Button>
                      {/* A disabled button gets no hover events: the
                          tooltip sits on a wrapper. */}
                      <span
                        className="inline-block"
                        title={
                          used.length > 0
                            ? `Used by ${used.length === 1 ? "1 app" : `${used.length} apps`}: remove its WF_STORAGE_ variables first`
                            : "Remove storage"
                        }
                      >
                        <Button
                          size="icon"
                          variant="ghost"
                          className="size-8 text-muted-foreground hover:text-destructive"
                          aria-label={`Remove storage ${s.name}`}
                          disabled={used.length > 0}
                          onClick={() => setToDelete(s)}
                        >
                          <Trash2 className="size-4" />
                        </Button>
                      </span>
                    </TableCell>
                  </TableRow>
                );
              })}
            </TableBody>
          </Table>
        )}
      </CardContent>
      <StorageDialog
        key={dialogKey}
        docker={docker}
        open={dialogOpen}
        edit={edit}
        onOpenChange={setDialogOpen}
        onSaved={saved}
      />
      <AlertDialog open={toDelete !== null} onOpenChange={(o) => !o && setToDelete(null)}>
        <AlertDialogContent>
          <AlertDialogHeader>
            <AlertDialogTitle>Remove this storage?</AlertDialogTitle>
            <AlertDialogDescription>
              <code className="font-mono text-foreground">{toDelete?.name}</code> is removed from this
              server. Nothing stored in it is deleted.
            </AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter>
            <AlertDialogCancel>Cancel</AlertDialogCancel>
            <AlertDialogAction
              className={buttonVariants({ variant: "destructive" })}
              onClick={() => {
                if (toDelete) void remove(toDelete.name);
              }}
            >
              Remove storage
            </AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </AlertDialog>
    </Card>
  );
}
```

```tsx
// StorageVariableRows lists the WF_STORAGE_ variables the compose files
// reference, read-only: their values come from the server's storages (Settings
// → Storages), and a secret shows only as <encrypted>.
function StorageVariableRows({ vars }: { vars: StorageVariable[] }) {
  if (vars.length === 0) return null;
  return (
    <ul aria-label="Storage variables" className="mt-2 divide-y rounded-md border bg-muted/30">
      {vars.map((v) => (
        <li key={v.name} className="flex flex-wrap items-center gap-x-3 gap-y-1 px-3 py-2 text-sm">
          <code className="font-mono [overflow-wrap:anywhere]">{v.name}</code>
          {v.secret ? (
            <span className="flex items-center gap-1 font-mono text-xs text-muted-foreground">
              <Lock className="size-3" /> {"<encrypted>"}
            </span>
          ) : null}
          <span className="ml-auto text-xs text-muted-foreground">
            provided by storage <code className="font-mono">{v.storage}</code>
          </span>
        </li>
      ))}
    </ul>
  );
}
```
